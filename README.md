# The Perfect Pickup Line

An entry for the make.fun bounty [The Perfect Pickup Line](https://make.fun/bounty/u-pucuys-the-perfect-pickup-line-f6725cf6). The program writes a single short pickup line an AI agent could actually say out loud to a person — an AI-flavored twist on the classic "Are you X? Because..." format, built around the system prompt that starts everything an agent does — to `/output/entry.txt`, using only the Python standard library.
